# Healthcare Analytics Dashboard

## Project Overview
An end-to-end healthcare analytics project built during my Business Analyst internship at AIVariant (Jan–Apr 2026).
Analyzed 10,000+ patient records across departments to surface key operational KPIs for stakeholder decision-making.

## Problem Statement
The healthcare client lacked a centralized view of operational performance. Department heads were spending 3+ hours
per week on manual data pulls with no consistent KPI definitions across teams.

## Objective
Design and deliver interactive dashboards that give stakeholders real-time visibility into patient flow,
resource utilization, and lab performance — with validated, consistent data across all reporting tools.

## Tools Used
| Tool     | Purpose                                      |
|----------|----------------------------------------------|
| SQL      | Data extraction, cleaning, transformation    |
| Excel    | Exploratory analysis, pivot tables, charts   |
| Power BI | Interactive KPI dashboard (operational view) |
| Tableau  | Drill-through dashboard by dept & diagnosis  |

## Key KPIs Tracked
- Patient visit volume (daily / monthly trend)
- Doctor utilization rate (by department)
- Lab result turnaround time
